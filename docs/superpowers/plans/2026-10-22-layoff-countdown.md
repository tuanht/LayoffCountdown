# Layoff Countdown Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu-bar-only macOS app plus a medium desktop widget that count down to the user's layoff moment, distributed as a DMG.

**Architecture:** Pure logic (settings, storage with fallback, formatting, jokes, progress, widget schedule) lives in a local Swift package `LayoffCore`, tested with `swift test`. Two thin SwiftUI targets consume it: the app (`MenuBarExtra` + settings `Window`) and a WidgetKit extension. The Xcode project is generated by XcodeGen from `project.yml`; the generated `.xcodeproj` is committed so teammates can build with Xcode alone.

**Tech Stack:** Swift 5.10+, SwiftUI, WidgetKit, ServiceManagement (`SMAppService`), XcodeGen (dev-only, `brew install xcodegen`), `hdiutil` for the DMG.

**Spec:** `docs/superpowers/specs/2026-10-22-layoff-countdown-design.md`

## Global Constraints

- Deployment target: macOS 14.0 for both targets and the package (`.macOS(.v14)`).
- No network access of any kind: no `URLSession`, no analytics, no crash reporters, no third-party runtime dependencies. No network entitlements (`com.apple.security.network.client` must not be present).
- App is menu-bar only: `LSUIElement = YES`. No Dock icon.
- Default emoji `💀`. Menu bar default style short: `💀 23d 4h`. Full style: `💀 23d 04:17:52`.
- Not set: menu bar `💀 Set date`; widget `Set your date in the app`.
- At zero: menu bar `💀 Goodbye`; widget farewell line `Goodbye. Hand in your laptop on the way out.` Never show negative or overtime values.
- Default layoff time of day: 17:00, local time zone.
- Jokes stay about the situation; never name a person or company.
- Bundle IDs: app `com.layoffcountdown.app`, widget `com.layoffcountdown.app.widget`. App Group: `$(DEVELOPMENT_TEAM).com.layoffcountdown.shared`.
- Builds and runs without any Apple account (ad-hoc "Sign to Run Locally").
- One "day" in every countdown = 86,400 seconds counted back from the layoff moment (not calendar days), so the menu bar and widget always agree.

## Review Focus

1. **Layoff moment already in the past** (entered by mistake, or the clock passes zero while the app runs): show Goodbye states, never `-1d` or `00:00:00` stuck. Pinned in Task 2 (`testPastDeadlineIsDone`, `testExactlyZeroIsDone`).
2. **Start date on or after the layoff moment**: progress is `1.0`, never NaN/infinite/crash. Pinned in Task 4 (`testProgressStartAfterDeadline`).
3. **Emoji field empty, whitespace, or a pasted sentence**: falls back to `💀` / keeps only the first character. Pinned in Task 3 (`testEmojiSanitizing`).
4. **Stored settings unreadable** (corrupt JSON, App Group unavailable because no team is set): defaults, no crash; the menu bar app still saves to standard defaults. Pinned in Task 3 (`testCorruptDataLoadsDefaults`, `testNoAppGroupFallsBackToStandard`).
5. **Day rollover in the widget clock**: widget shows `22d 23:59:59` right after `23d 00:00:00`, matching the menu bar, not `23d 00:00:00` frozen or `0:00:00`. Pinned in Task 4 (`testScheduleHasEntryAtEachDayBoundary`).

### Task 4: Jokes, progress, widget schedule

**Files:** Create `Sources/LayoffCore/Jokes.swift`, `Progress.swift`, `WidgetSchedule.swift`, and `Tests/LayoffCoreTests/JokesTests.swift`, `ProgressTests.swift`, `WidgetScheduleTests.swift`.

**Interfaces:**
- Consumes: `CountdownFormatter.parts` (Task 2).
- Produces:
  - `public enum Jokes { static let all: [String]; static func joke(for date: Date, calendar: Calendar) -> String; static let farewell = "Goodbye. Hand in your laptop on the way out." }` — index = (days from 2026-01-01 to the start of `date`'s day in `calendar`) mod `all.count`, non-negative.
  - `public enum NoticeProgress { static func fraction(start: Date?, deadline: Date, now: Date) -> Double }` — clamp to `0...1`; `start == nil` or `start >= deadline` → `1.0`.
  - `public enum WidgetSchedule { static func entryDates(now: Date, deadline: Date?, calendar: Calendar) -> [Date]; static func dayBoundary(before deadline: Date, now: Date) -> Date }` — `dayBoundary` = `deadline - days*86400` where `days = parts(deadline - now).days`, i.e. the moment the day digit next changes is that boundary; the widget renders `"\(days)d "` + a timer counting down to it.
  - `entryDates` returns, sorted and unique: `now`; every day boundary (`deadline - k*86400`) after `now` within the next 48 hours; the deadline itself if within 48 hours; the next local midnight (joke change). If `deadline` is nil or past, returns `[now, nextMidnight]`. Reload policy in Task 7 is `.after(last entry)`.
